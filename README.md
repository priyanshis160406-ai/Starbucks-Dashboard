A dynamic, interactive Power BI dashboard built to analyze Starbucks beverage nutritional data - focusing on calorie distribution, sugar content, caffeine strength, and category-wise trends.Purpose
The Starbucks Brewing Insights Dashboard is a visually engaging Power BI report designed to help users explore and compare 33+ Starbucks beverages across multiple categories. The dashboard focuses on highlighting nutritional facts like average calories, sugar, caffeine and protein to guide healthier choices. This tool is intended for health-conscious consumers, data analysts, and business strategists who want to understand consumer beverage preferences through data.


The dashboard was built using the following tools and technologies:
- 📊 Power BI Desktop - Main data visualization platform used for report creation.
- 📁 Power Query - Data transformation and cleaning layer for reshaping the Starbucks dataset.
- 🧮 DAX (Data Analysis Expressions) - Used for calculated measures like Avg Caffeine, Avg Sugar, Avg Calories.
- 📄 Data Modeling - Relationships and measures for aggregation.
- 📂 File Format - .pbix for development and .png/.pdf for dashboard preview.


Source: Kaggle - Starbucks Nutrition Data & Starbucks Menu Dataset

Data on ~33 Starbucks beverages, including details on their Beverage Category, Calories, Sugar, Protein, Caffeine, and Preparation type.



- **Business Problem**
The global coffee chain industry generates billions, yet customers often lack a clear, visual way to compare beverages based on health metrics. High sugar and calorie drinks are consumed unknowingly.

- **Goal of the Dashboard**
To provide a one-page health-focused view of Starbucks menu, helping users choose drinks based on caffeine needs vs calorie/sugar intake, and help the business identify which categories drive indulgence vs energy.

- **Walk through of key visuals (briefly!)**
    - KPI Cards (Total Beverage, Avg Sugar, Avg Calories, Avg Caffeine) - Top level summary.
    - Average Calories by Beverage Category (Area Chart) - Shows Smoothies & Frappuccino Blended Drinks have highest calories (282, 276).
    - Starbucks Global Presence (Column Chart) - Shows count of drinks per category, Coffee dominates.
    - Beverage Category Distribution (Donut Chart) - Category share % with central logo.
    - Average Caffeine by Category (Bar Chart) - Coffee leads with 294 avg caffeine.
    - Top 5 Highest Caffeine Beverages (Image + Card) - Coffee 293.75mg, Classic Espresso 122.07mg, Frappuccino Blended 101.81mg, Frappuccino Light 99.58mg, Iced Beverages 98.53mg.

- **Business Impact & Insights**
    - Product Positioning: Highest caffeine is in plain Coffee, best for energy-seeking customers.
    - Health Awareness: Frappuccinos & Smoothies drive sugar and calories - can be flagged as indulgence drinks.
    - Menu Optimization: Low-caffeine, low-calorie options like Iced Beverages can be promoted to health-conscious audience.
    - Customer Decision: Users can instantly filter by Protein Range and Beverage Prep.
